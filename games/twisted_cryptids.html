เล่น 5 รอบ ทุกรอบเป็นแบบนี้

  1. รุ่งเช้า Dawn: First Player เปิดการ์ดเหตุการณ์ Event 1 ใบ มนุษย์ในป่าขยับไปเองตามการ์ด
  2. กลางวัน Day: เวียนกันคนละ 3 ตา ตาละ 1 อย่าง: เล่นการ์ด Action, ทิ้งการ์ดเพื่อใช้พลัง Cryptid (รอบละครั้ง) หรือผ่าน
  3. โพล้เพล้ Dusk: เกิด Encounter ที่ Site ที่มีมนุษย์มากที่สุด (ต้องมีที่ซ่อนอย่างน้อย 1 อัน) ทุกคนที่ซ่อนอยู่ตรงนั้นเปิด Sighting ใบบนสุดของกองที่ตรงกัน ได้หรือเสีย Myth ตามมนุษย์ที่อยู่ตรงนั้น
  4. กลางคืน Night: ย้ายที่ซ่อน ทิ้งการ์ดแล้วจั่วให้ครบ 5 ใบ ส่ง First Player token ไปทางซ้าย

จบ 5 รอบ เปิดการ์ดที่เหลือทั้งหมด ได้ +7 Myth ต่อ Real Deal ที่ไม่เคยถูกเปิด บวกโบนัสจาก Hidden Trait ใครมี Myth มากสุดคือ True Legend (ผู้ชนะ)

ประเภทการ์ด

การ์ดแอ็กชัน Action

อยู่ในมือ 5 ใบ เล่นในช่วงกลางวันเพื่อย้ายมนุษย์ แต่ละใบบอก จำนวน, ชนิดมนุษย์ Flavor และ Function (Lure, Scare, Attract, Extract …) เล่นแล้วทำตาม แล้วลงกองทิ้ง

OR card เลือกทำ 1 อย่าง · AND card NESS IS MORE ทำทุกอย่างทีละอย่าง เรียงตามที่เราเลือก จะทำจากที่ซ่อนอันเดียวกันหรือคนละอันก็ได้

การ์ดเหตุการณ์ Event

เปิดรอบละ 1 ใบตอนรุ่งเช้า วางหงายบนกอง Current Event pile แล้วทำตามจากบนลงล่าง ทำให้มนุษย์เข้า ออก หรือย้ายในป่าเอง ไม่มีใครเป็นเจ้าของการ์ดนี้

การ์ดพบเห็น Sighting

คนละ 9 ใบ อยู่ในกอง 3 กอง เปิดตอน Encounter ได้หรือเสีย Myth ตามจำนวนมนุษย์แต่ละชนิดที่ Site นั้น แล้วทำเอฟเฟกต์บนการ์ด เปิดแล้ววางหงายไว้ข้างตัว

การ์ดนิสัยลับ Hidden Trait

เป้าหมายลับ 1 ใบ (แจก 2 เลือก 1) ทำได้มากก็ได้โบนัส Myth มากตอนจบเกม มี 3 ระดับ levels of completion ดูของตัวเองได้ตลอด แต่เปิดให้คนอื่นเห็นตอนจบเกมเท่านั้น

Hiker นักเดินป่า

มนุษย์ทั่วไป ไม่ได้ตามหาเรา แต่ถ้าเจอก็สงสัย ตอนรุ่งเช้ามักเดินเที่ยวไปทั่วป่า โดน Hoax หลอกง่าย และมักปล่อยเราไว้ถ้าเจอเรากำลังนอน

Hunter นักล่า

ตามล่าเราจริงจัง ตอนรุ่งเช้ามักย้ายเป็นฝูงและย้ายไกล แพ้ทางหุ่นล่อ (Decoy) และกลัวเวลาเห็นเราตั้งท่าจะโจมตี

Researcher นักวิจัย

อยากพิสูจน์ว่าเรามีจริง ตอนรุ่งเช้าย้ายช้า ๆ ไปที่ที่คนน้อย ตื่นเต้นกับ Silhouette และดีใจที่สุดถ้าจับได้ว่าเรากำลังทำเรื่องธรรมดาหรือเรื่องตลก

บางเอฟเฟกต์ใช้สัญลักษณ์มนุษย์กลาง ๆ แทนชนิด แปลว่า เลือกมนุษย์ชนิดไหนก็ได้ · คู่มือเรียกชนิดมนุษย์ว่า Flavor (รสชาติ) เพราะในสายตา Cryptid มนุษย์คืออาหาร

ภาษาบนการ์ด

วิธีย้ายมนุษย์ (Functions)

ทุกการ์ด Action และพลัง Cryptid ใช้คำเหล่านี้ ★ คือ Site ที่มีที่ซ่อนของเรา เส้นทึบคือทางหลัก เส้นประคือทางที่เลือกได้ด้วย

เมื่อทำไม่ได้ครบ

ถ้าทำเอฟเฟกต์ได้ไม่ครบ ให้ทำเท่าที่ทำได้ partially resolve เช่น การ์ดบอก Lure 2 Researchers แต่ Site ข้าง ๆ มี Researcher แค่ 1 คน ก็ยังเล่นการ์ดได้และ Lure 1 คน · แต่ถ้ามี 2 คน ต้อง Lure ทั้ง 2 คน กฎนี้ใช้กับการ์ด Event, Action, พลัง Cryptid และ Sighting ทั้งหมด

คำบนการ์ด Event

  • TO ย้ายมนุษย์ไปที่ Site นั้นโดยตรง
  • TOWARD ย้ายเข้าใกล้ Site นั้น 1 ก้าว (ไป Site ที่ติดกันที่อยู่ทางนั้น) อาจถึงเลยหรือแค่ใกล้ขึ้น ถ้ามีสองทางที่ใกล้เท่ากัน เลือกเอง
  • distribute หยิบมนุษย์ที่ระบุออกจาก Site แล้วแจกไป Site ที่ติดกันให้เท่า ๆ กันที่สุด ถ้าเศษ เลือกเองว่า Site ไหนได้เพิ่ม
  • ถ้ามีหลาย Site ตรงเงื่อนไข (เช่น มีมนุษย์มากสุดเท่ากัน) เลือกมา 1 Site แล้วทำจากที่นั่น
  • Site ที่มีมนุษย์น้อยที่สุด fewest นับรวม Site ที่มี 0 คนด้วย
ก่อนเริ่ม

เตรียมเกม 5–6 คน

  1. กางบอร์ด วาง Myth token

    วาง The Wilderness ไว้กลางโต๊ะ วาง Myth token ทั้งหมดไว้ข้าง Myth Track

  2. วางมนุษย์

    แยกมนุษย์เป็น 3 Rest Area ตามชนิด (ใส่ Human 6 อันจาก Ness is More รวมด้วย) แล้ววาง Hiker, Hunter, Researcher ลงบนทุก Site ตามสัญลักษณ์ที่พิมพ์ไว้บน Site

  3. ผสมสำรับ

    สับการ์ด Action ของกล่องหลักรวมกับ Ness is More วางคว่ำ เว้นที่ไว้เป็นกองทิ้ง · สับการ์ด Event รวมทั้งสองกล่อง วางคว่ำ เว้นที่ไว้เป็น Current Event pile

  4. เลือก Cryptid

    แต่ละคนเลือก 1 ตัว รับการ์ด Cryptid, หมาก, Sighting 9 ใบ และ Hiding Spot 3 อันของตัวนั้น วางหมากที่ 5 Myth บน Myth Track ตัวที่เหลือเก็บกล่องพร้อมของทั้งชุด

  5. เลือก Hidden Trait

    สับ Hidden Trait ของทั้งสองกล่องรวมกัน แจกคนละ 2 ใบ เลือกเก็บ 1 ใบคว่ำไว้เหนือการ์ด Cryptid ที่เหลือเก็บกล่อง

  6. จัด 3 กอง Sighting

    แอบเลือก Sighting 3 ใบ วางคว่ำซ้อนกันตามลำดับที่ต้องการ ทำซ้ำจนได้ 3 กอง กองละ 3 ใบ วางเรียงทางขวาของการ์ด Cryptid: ซ้าย = ที่ซ่อนเลข 1, กลาง = 2, ขวา = 3

  7. เลือก First Player

    ให้ First Player token กับคนที่ไปสวนสาธารณะล่าสุด

  8. วางที่ซ่อน 3 รอบ

    • ยกที่ซ่อนออกจาก Site ไปวางบนกองของมัน แล้วคนถัดไปเปิด

Site ที่มีมนุษย์เยอะที่สุดไม่มีใครซ่อนอยู่ จะเกิด Encounter ไหม

ไม่เกิดที่นั่น Encounter ต้องเกิดที่ Site ที่มีที่ซ่อนอย่างน้อย 1 อัน ให้ดู Site ที่มีมนุษย์มากที่สุดในบรรดา Site ที่มีที่ซ่อน

ไม่ได้ ทั้งตอนเริ่มเกมและตอนย้ายกลางคืน ดังนั้นแต่ละ Encounter เราเปิด Sighting ได้มากสุด 1 ใบ

ใช้ Cryptid Power ไปแล้ว ยังเล่นการ์ด Action ได้ไหม

ดูการ์ด Sighting ในกองของตัวเองได้ไหม สลับลำดับได้ไหม

ดูได้ตลอด และดู Hidden Trait ของตัวเองได้ตลอดเช่นกัน แต่คู่มือไม่ได้ให้สลับลำดับหลังจัดกองแล้ว ลำดับที่จัดตอนเริ่มเกมใช้ไปจนจบ

เปิด Sighting แล้ว Myth ไม่พอหัก

Myth ลดลงต่ำสุดแค่ 0 ไม่ติดลบ

กองหมดแล้ว ที่ซ่อนเลขนั้นทำไง

เก็บโทเคนที่ซ่อนเลขนั้นลงกล่อง ใช้ไม่ได้อีก จากนั้นเราจะมีที่ซ่อนในป่าน้อยลง

ถ้าเล่น 6 คนแล้วทุก Site เต็ม 4 คน จะย้ายที่ซ่อนไปไหน

รอบที่ 5 ช่วงกลางคืนยังต้องย้ายที่ซ่อนไหม

ยังทำตามขั้นตอนปกติ ยกเว้นไม่จั่วการ์ด (ทิ้งที่เหลือทั้งหมด) ตำแหน่งที่ซ่อนสุดท้ายมีผลตอนตัดสินเสมอ เพราะนับมนุษย์ใน Site ที่เรามีที่ซ่อน

  • ถ้า Sighting บนสุดเสียเปรียบ ให้ไล่มนุษย์ออก (Scare, Extract) หรือทำให้ Site อื่นคนเยอะกว่า Encounter จะได้ไปเกิดที่อื่น
  • ดูว่าใครเปิดก่อนเราใน Encounter เดียวกัน เอฟเฟกต์ของเขาอาจย้ายมนุษย์ก่อนถึงตาเรา
  • Real Deal ที่ฝังไว้ล่างสุดคือ +7 ที่ค่อนข้างแน่นอน เพราะโดน Encounter ที่ซ่อนเดียวกันครบ 3 ครั้งใน 5 รอบได้ยาก
  • เก็บการ์ด Strong Lure / Big Scare ไว้ใช้ตาท้าย ๆ ของกลางวัน ตอนที่คนอื่นแก้เกมไม่ทันแล้ว
  • ทำ Hidden Trait ให้ถึงระดับสูงสุดได้โบนัสเยอะ ตัดสินใจเรื่องจะเปิดหรือไม่เปิด Sighting โดยดู Hidden Trait ของตัวเองไปด้วย
