# Flip 7 (พลิก 7) — ตารางตรวจตัวเลข

กล่อง: ฉบับไทย "FLIP 7 การ์ดไม่ซ้ำ ทำให้ได้" ของ Tower Tactic Games (กล่องแข็ง) ผู้ใช้เรียกว่า "พลิก 7"
หาคู่มือไทยเป็น PDF ไม่ได้ คู่มือนี้อิงคู่มือภาษาอังกฤษของ The Op (USAopoly) Ruleset Edition 3.1

- **PDF** = คู่มือทางการ The Op "FLIP 7 RULES" Ruleset Edition 3.1 (ไฟล์บน cdn ของ Asmodee) https://cdn.svc.asmodee.net/production-asmodeeca/uploads/2025/12/FLIP_7-RULES.pdf

- **RP** = rulespal.com Flip 7 rulebook https://rulespal.com/flip-7/rulebook
