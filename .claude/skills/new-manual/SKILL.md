# ทำคู่มือบอร์ดเกมเล่มใหม่

ทำตามขั้นตอนนี้ครบทุกข้อตามลำดับ ห้ามข้ามขั้น ตอบผู้ใช้เป็นภาษาไทย

**หลักการ:** หัวใจของคู่มือคือช่วยผู้เล่นใหม่ให้เล่นเป็นเร็วที่สุด template และสคริปต์ตรวจเป็นแค่มาตรฐานขั้นต่ำ ไม่ใช่แม่พิมพ์
ออกแบบแต่ละเล่มให้เข้ากับเกมนั้น (หัวข้อ ภาพ เครื่องมือ ลำดับการอธิบาย สี) ห้ามตัดสิ่งที่ช่วยผู้เล่นใหม่เพียงเพื่อให้ตรงโครง
ก่อนส่งงาน ให้อ่านทวนแบบคนไม่เคยเล่นเกมนี้: อ่านจบแล้วตั้งโต๊ะเล่นได้ไหม เปิดกลางเกมแล้วหาคำตอบเจอไหม

## 0. เตรียม
1. `git pull` ใน repo นี้ก่อนเสมอ
2. อ่าน `README.md` ทั้งไฟล์ (กฎทั้งหมดอยู่ที่นั่น รวมถึง "หมายเหตุรายเกม")
3. อ่านเล่มต้นแบบ `games/carcassonne_big_box.html` ส่วน HTML (หัวไฟล์ถึง `</footer>`) เพื่อจับระดับความละเอียดและน้ำเสียง
4. อ่าน `templates/manual.html` ทั้งไฟล์

## 1. ยืนยันฉบับของกล่อง (ห้ามข้าม)
- ใช้ข้อมูลจากแบบฟอร์มใน `templates/NEW_GAME_REQUEST.md` ที่ผู้ใช้กรอกมา
- ถ้าช่องไหนว่างหรือเขียนว่า "ไม่แน่ใจ" ในเรื่อง **สำนักพิมพ์ / ภาษา / จำนวนผู้เล่นบนกล่อง / ภาคเสริมในกล่อง** ให้ถามผู้ใช้ก่อน (AskUserQuestion) ห้ามเดาฉบับเอง
- ถ้าเกมมีหลายฉบับ (เช่น 1st/2nd edition, ฉบับไทยกับฉบับอังกฤษ) ให้บอกความต่างสั้น ๆ แล้วให้ผู้ใช้เลือก

## 2. ค้นคว้าและตรวจตัวเลข
- หาคู่มือทางการ (PDF ของสำนักพิมพ์) เป็นแหล่งหลัก + แหล่งรองอีกอย่างน้อย 1 (BGG, คู่มือฉบับอื่นของสำนักพิมพ์, rulespal ฯลฯ)
- สร้าง `notes/<ชื่อไฟล์>.md` เป็นตาราง: `ตัวเลข/กติกา | ค่า | แหล่ง 1 | แหล่ง 2 | สถานะ`
  - ใส่ **ทุกตัวเลข**: จำนวนชิ้น, แต้ม, จำนวนผู้เล่น, เวลา, จำนวนแอ็กชัน, ค่าที่ต่างตามจำนวนผู้เล่น
  - สถานะ = `ยืนยัน` เมื่อ 2 แหล่งตรงกัน · `ขัดกัน` / `หาไม่เจอ` ถ้าไม่ครบ
- ตัวเลขที่ไม่ได้ `ยืนยัน` ห้ามเขียนเหมือนเป็นข้อเท็จจริง ให้ติด `<span class="unverified">ยังไม่ยืนยัน</span>` ในคู่มือ และบอกผู้ใช้ตอนสรุป
- กฎบ้านติด `<span class="house">กฎบ้าน</span>` และแยกจากกติกาทางการให้ชัด

## 3. เขียนคู่มือ
1. ตั้งชื่อไฟล์: ชื่ออังกฤษตามกล่อง ตัวเล็ก คั่นด้วย `_` ตัด `: ! ' &` เช่น `7_wonders_architects.html`
2. คัดลอก `templates/manual.html` เป็น `games/<ชื่อไฟล์>.html` แล้วแทนที่ทุกช่อง `{{...}}`
3. ขั้นต่ำที่ต้องมี (เทียบระดับเล่มต้นแบบ แล้วเพิ่มของเฉพาะเกมได้เต็มที่):
   - `<title>` = "ชื่ออังกฤษ ฉบับไทย" · h1 = ชื่ออังกฤษ + `<span>` ชื่อไทย · คำอธิบาย
   - eyebrow = "คู่มือภาษาไทย · ภาคที่มีในกล่อง · อิงคู่มือทางการ (สำนักพิมพ์)"
   - hero: lede + facts + ป้ายภาคเสริม (ถ้ามี) + ภาพ SVG วาดเอง
   - หัวข้อพื้นฐาน (id): summary (+ `.formula`) · box (ตารางจำนวนชิ้นจริง) · setup · turn · end · faq (≥ 6 ข้อ) · glossary · footer แหล่งที่มา
     ลำดับตั้งต้น: summary → box → setup → turn → กติกาแยกทีละเรื่อง → end → ภาคเสริมทีละภาค (`.xhead`) → tools → faq → glossary
     ชื่อหัวข้อและลำดับปรับได้ตามเกม (เช่น เกมเป็นรอบใช้ "หนึ่งรอบเล่น") ขอแค่ใช้ id พื้นฐาน
   - หัวขั้นตอน/กติกามีชื่ออังกฤษตามคู่มือทางการใน `<span class="en">` (≥ 10 จุด)
   - ทุกสูตรแต้มมีตัวอย่างตัวเลขจริง และมีประโยค "ถ้ากล่องพิมพ์ต่างจากคู่มือนี้ ให้ยึดคู่มือในกล่อง"
   - ภาพ SVG วาดเองในกติกาสำคัญทุกเรื่อง (≥ 3 ภาพ) ใช้ class `s-fg / s-muted / s-acc ...` ให้รองรับโหมดมืด
   - ถ้าเกมมีกติกาต่างตามจำนวนผู้เล่น ต้องมีตารางแยกครบทุกจำนวนผู้เล่นบนกล่อง
4. เปลี่ยนสีใน `:root` ให้เข้ากับกล่องเกม (ทั้งโหมดสว่างและมืด) ส่วน `.shelf-home` ห้ามแตะ
5. สมุดคะแนนใน template ใช้ได้ทันที: แก้ `KEY` (ไม่ซ้ำเล่มอื่น), `CATS`, และ `min/max` ของ `#pad-n` ตามจำนวนผู้เล่น เพิ่มเครื่องมือเฉพาะเกมได้ (localStorage ต้องครอบ try/catch, ข้อความผู้ใช้ต้องผ่าน `esc()`)

## 4. ขึ้นชั้น
1. เพิ่มรายการใน `GAMES` ของ `index.html` ตามฟิลด์ใน README (`url:"games/<ชื่อไฟล์>.html"`, `added:"YYYY-MM-DD"` = วันนี้)
2. เพิ่มภาพกล่องใหม่ใน `ART` (viewBox `0 0 240 118`) **ห้ามแก้ภาพเดิม**
3. เพิ่มบรรทัดใน `CHANGELOG.md` ใต้วันที่วันนี้: `- เพิ่ม: <ชื่อเกม> — <ภาคที่มี / จุดเด่น>`

## 5. ตรวจ (ต้องผ่านก่อนไปขั้นต่อไป)
1. `python tools/check_manual.py games/<ชื่อไฟล์>.html --strict` ต้องได้ **ERROR 0 · WARN 0**
   (INFO "มีข้อมูลที่ติดป้ายยังไม่ยืนยัน" ไม่นับเป็น WARN แต่ต้องบอกผู้ใช้)
2. เปิด `python -m http.server 8765` แล้วดูใน Browser pane:
   - หน้า `index.html` มีกล่องเกมใหม่ กดแล้วเปิดคู่มือได้ ปุ่ม "ชั้นคู่มือ" กลับมาได้
   - ดูขนาดมือถือ (`resize_window` preset mobile) และโหมดมืด ไม่มีอะไรล้นจอ
   - ลองเครื่องมือทุกตัว ไม่มี error ใน console
3. ไล่เช็กกฎใน README ทีละข้ออีกรอบ และเทียบโครงกับเล่มต้นแบบ

## 6. ส่งงาน
1. commit (ข้อความภาษาไทย บอกเกมที่เพิ่ม) แล้ว `git push`
2. เผยแพร่ทับ Artifact ชั้นคู่มือเดิม https://claude.ai/artifact/EPowWYh6rZfXzWXSsykk6C
   - `read` เวอร์ชันล่าสุดก่อน แล้ว publish `index.html` เป็นหน้าหลัก พร้อม `files` = `games/*.html` ทุกไฟล์
   - ห้ามสร้าง Artifact แยกต่อเล่ม
3. สรุปให้ผู้ใช้: ไฟล์ที่ได้, ตัวเลขที่ยังไม่ยืนยัน (ถ้ามี), ผลสคริปต์ตรวจ, ลิงก์ชั้น
