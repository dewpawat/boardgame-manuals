# แบบฟอร์มสั่งทำคู่มือเล่มใหม่

คัดลอกข้อความในกรอบด้านล่าง กรอกให้ครบ แล้ววางในแชต Claude Code ที่เปิดโฟลเดอร์ repo นี้
ช่องที่ไม่รู้ให้เขียนว่า `ไม่แน่ใจ` แล้ว Claude จะถามต่อก่อนลงมือ (จะไม่เดาเอง)

```
/new-manual
เกม (ชื่ออังกฤษตามกล่อง):
ชื่อไทยที่ใช้เรียก:
ฉบับ / สำนักพิมพ์ / ภาษาของกล่อง:
จำนวนผู้เล่นบนกล่อง:
เวลาเล่นบนกล่อง:
ภาคเสริมที่มีในกล่อง (หรือ "ไม่มี"):
กฎบ้านที่เล่นประจำ (หรือ "ไม่มี"):
หมวดบนชั้น (engine / pattern / tile / route / deduce / party / rollmove / abstract / trick / หมวดใหม่):
ลิงก์คู่มือ PDF ทางการ (ถ้ามี):
เครื่องมือที่อยากได้ในหน้า (ถ้าไม่ระบุ = ตัวช่วยเตรียมเกม + สมุดคะแนน):
```

## ตัวอย่างที่กรอกแล้ว

```
/new-manual
เกม (ชื่ออังกฤษตามกล่อง): Wingspan
ชื่อไทยที่ใช้เรียก: วิงสแปน
ฉบับ / สำนักพิมพ์ / ภาษาของกล่อง: Stonemaier Games ฉบับภาษาอังกฤษ
จำนวนผู้เล่นบนกล่อง: 1–5
เวลาเล่นบนกล่อง: 40–70 นาที
ภาคเสริมที่มีในกล่อง (หรือ "ไม่มี"): European Expansion
กฎบ้านที่เล่นประจำ (หรือ "ไม่มี"): ไม่มี
หมวดบนชั้น: engine
ลิงก์คู่มือ PDF ทางการ (ถ้ามี): ไม่แน่ใจ
เครื่องมือที่อยากได้ในหน้า: เครื่องคิดคะแนนท้ายเกม + สมุดคะแนน
```

## สิ่งที่จะได้

1. `games/<ชื่อเกม>.html` โครงเดียวกับเล่มต้นแบบ Carcassonne ผ่านสคริปต์ตรวจแบบ `--strict` (ERROR 0 · WARN 0)
2. `notes/<ชื่อเกม>.md` ตารางตรวจตัวเลขทุกตัวพร้อม 2 แหล่งอ้างอิง
3. รายการใหม่ใน `GAMES` + ภาพกล่องใน `ART` ของ `index.html`
4. บรรทัดใหม่ใน `CHANGELOG.md`
5. commit + push แล้วเว็บ https://dewpawat.github.io/boardgame-manuals/ อัปเดตเอง (ถ้าสั่งว่า "เพิ่มเข้าชั้นคู่มือ")
