# ชั้นคู่มือบอร์ดเกม (Board Game Manuals TH)

คู่มือบอร์ดเกมภาษาไทย 1 เกมต่อ 1 ไฟล์ HTML มีหน้า `index.html` เป็นชั้นคู่มือและสารบัญรวม
เป็นงานอดิเรก ไม่ใช่งานราชการ คู่มือทุกเล่มเรียบเรียงจากคู่มือทางการ และบอกแหล่งที่มาไว้ท้ายเล่ม

- เว็บที่เผยแพร่ (Artifact): https://claude.ai/artifact/EPowWYh6rZfXzWXSsykk6C
- ต้นฉบับ: repo นี้ (ใช้ร่วมกันทั้งเครื่องที่ทำงานและเครื่องที่บ้าน)
- ประวัติการเพิ่มและแก้ไข: [CHANGELOG.md](CHANGELOG.md)

## โครงไฟล์

```
index.html                  ← ชั้นคู่มือ + สารบัญ (ข้อมูลเกมอยู่ใน GAMES, หมวดอยู่ใน CATS)
games/<ชื่อเกม>.html         ← คู่มือ 1 เล่ม 1 ไฟล์ ห้ามรวมไฟล์
README.md                   ← ไฟล์นี้ (กฎทั้งหมดอยู่ที่นี่)
CHANGELOG.md                ← บันทึกการเพิ่ม/แก้ไข
```

- ทุกหน้าเป็น HTML ไฟล์เดียวจบ CSS/JS/SVG ฝังในไฟล์ ใช้ภายนอกได้แค่ Google Fonts
- ลิงก์ระหว่างหน้าใช้ path แบบ relative: ชั้น → `games/xxx.html`, คู่มือ → `../index.html`

## กฎการตั้งชื่อไฟล์

- ใช้ชื่อเกมภาษาอังกฤษตามกล่อง ตัวพิมพ์เล็กทั้งหมด คั่นคำด้วย `_` (snake_case)
- ตัดเครื่องหมาย `:` `!` `'` `&` ออก ตัวเลขคงไว้ตามชื่อจริง
- ตัวอย่าง: `7_wonders_architects.html`, `carcassonne_big_box.html`, `6_nimmt.html`,
  `azul_master_chocolatier.html`, `the_resistance_avalon.html`

## วิธีดูในเครื่อง

```bash
python -m http.server 8765
```
แล้วเปิด http://127.0.0.1:8765/ (หรือผ่าน Laragon ที่ http://localhost/boardgame-manuals/)

## วิธีเพิ่มคู่มือเล่มใหม่

1. ถามให้ชัดก่อนว่ากล่องเป็นฉบับไหน (สำนักพิมพ์ จำนวนผู้เล่นบนกล่อง) ถ้าไม่แน่ใจห้ามเดาเอง
2. อ่านเล่มต้นแบบ `games/carcassonne_big_box.html` แล้วเขียนเล่มใหม่ตามโครงเดียวกัน (ดูกฎด้านล่าง)
3. บันทึกเป็น `games/<ชื่อเกม>.html` ตามกฎการตั้งชื่อ
4. เพิ่ม 1 รายการใน `GAMES` ของ `index.html` (`url:"games/<ชื่อเกม>.html"`) และเพิ่มภาพใน `ART` ถ้าต้องการ
5. เพิ่มบรรทัดใน `CHANGELOG.md`
6. commit แล้ว push ขึ้น GitHub
7. เผยแพร่ทับ Artifact ลิงก์เดิม โดยส่ง `index.html` เป็นหน้าหลัก และส่ง `games/*.html` ทุกไฟล์เป็น `files`

### ฟิลด์ใน GAMES

- `cat`: id หมวดจาก `CATS` (ถ้าเป็นหมวดใหม่ ให้เพิ่มใน `CATS` ก่อน แล้วชั้นใหม่จะขึ้นเอง)
- `t`: เวลาเล่นตามที่พิมพ์บนกล่อง (ข้อความ), `tmax`: นาทีสูงสุด (ใช้กรองเวลาเล่น)
- `rules` / `score` / `extra`: เนื้อหาในคู่มือ เขียนเป็นวลีสั้นแบบเดียวกันทุกเล่ม
- `tools`: ชื่อเครื่องมือคั่นด้วย ` · ` ใช้ชื่อมาตรฐาน: ตัวช่วยเตรียมเกม, สมุดคะแนน, เครื่องคิดคะแนน
- `added`: วันที่ขึ้นชั้น `"YYYY-MM-DD"` (ใช้กับตัวเรียง "ขึ้นชั้นล่าสุด" เท่านั้น)
- ไม่ใช้ป้าย "ใหม่" บนกล่อง (ปิดไว้ เพราะช่วงนี้กำลังทยอยทำคู่มือให้ครบทุกเกมที่มี ทุกเล่มจึงใหม่หมด)
- `art`: ชื่อภาพใน `ART` (ภาพ SVG ของแต่ละกล่อง ห้ามแก้ของเดิม)

## กฎของชั้นคู่มือ

### ภาพรวม
- ชั้นนี้เป็นสารบัญและทะเบียนบอร์ดเกมที่มีคู่มือแล้ว เกมขึ้นชั้นได้เมื่อคู่มือเสร็จแล้วเท่านั้น
- มีคนอื่นเปิดดู ให้เขียนคำแบบทั่วไป ไม่ใส่คำพูดส่วนตัว (เช่น "ยังไม่เคยเล่น")
- ภาพ SVG ในก้อน `ART` ห้ามแก้ของเดิม (เจ้าของชอบมาก) เพิ่มภาพใหม่ได้อย่างเดียว
- ค่าเริ่มต้นของตัวเรียง = ชื่อ A–Z

### รูปแบบคู่มือแต่ละเล่ม
- ★★ **เล่มต้นแบบ (สำคัญที่สุด ห้ามข้าม)** = `games/carcassonne_big_box.html`
  เป็นเล่มที่ละเอียดและดีที่สุด ก่อนเขียนเล่มใหม่ต้องอ่านเล่มนี้ก่อนทุกครั้ง แล้วทำตามโครงเดียวกัน:
  - `<title>` = "ชื่อเกมภาษาอังกฤษ ฉบับไทย" · h1 = ชื่อเกมภาษาอังกฤษตามกล่อง (ไม่ใช่ชื่อไทย)
    แล้วใส่ `<span>` ใต้ h1 = ชื่อไทย · คำอธิบายเกมสั้น ๆ
  - eyebrow = "คู่มือภาษาไทย · ภาคที่มีในกล่อง · อิงคู่มือทางการ (สำนักพิมพ์)"
  - hero = lede อธิบายทั้งเกม + facts (ผู้เล่น เวลา ของสำคัญ) + ป้ายภาคเสริมที่กดไปหัวข้อได้ (ถ้ามี)
  - ลำดับหัวข้อ: สรุป 1 นาที (+ แถบสูตรแต้ม `.formula`) → ในกล่องมีอะไร (ตารางจำนวนชิ้นจริง)
    → เตรียมเกม → ในตาของคุณ → กติกาแยกทีละเรื่อง พร้อมภาพ SVG และตัวอย่างตัวเลข
    → ภาคเสริมทีละภาค (`.xhead` สีประจำภาค) → จบเกมและนับแต้ม → เครื่องมือ → ข้อที่ชอบเถียงกัน
    → ศัพท์ไทย-อังกฤษ → footer แหล่งที่มา
  - หัวขั้นตอน/กติกาใส่ชื่อภาษาอังกฤษตามคู่มือทางการใน `<span class="en">`
    เช่น วางไทล์ `<span class="en">Place a tile</span>`
  - ทุกสูตรแต้มต้องมีตัวอย่างตัวเลขจริง และเขียนว่า "ถ้ากล่องพิมพ์ต่างจากคู่มือนี้ ให้ยึดคู่มือในกล่อง"
- **กันพลาด:** ตัวเลขทุกตัว (จำนวนชิ้น แต้ม ผู้เล่น แอ็กชัน) ต้องตรวจจากแหล่งอย่างน้อย 2 แหล่ง
  ถ้าแหล่งขัดกันหรือหาไม่เจอ ให้เขียนในคู่มือตรง ๆ ว่ายังไม่ยืนยัน ห้ามเดาเอง
- ก่อนเผยแพร่: ไล่เช็กกับกฎในไฟล์นี้ทีละข้อ และเทียบโครงกับเล่มต้นแบบอีกรอบ
- ภาษาไทย มีสารบัญด้านข้าง ภาพประกอบ SVG วาดเอง วิธีนับคะแนนทุกภาค ข้อที่ชอบเถียงกัน
  เครื่องมือช่วยกลางโต๊ะ อิงคู่มือทางการ และบอกแหล่งที่มา
- ทุกเล่มต้องมีปุ่มกลับชั้นคู่มือ (`.shelf-home`) แบบเดียวกัน: ปุ่มเม็ดยาสีน้ำตาลไม้ `#5f3c1f` ตัวอักษรครีม
  ไอคอนชั้นวางกล่อง + คำว่า "ชั้นคู่มือ" ลิงก์ไป `../index.html` position:fixed มุมขวาล่าง (16px + safe-area)
  z-index 50 และ `body{padding-bottom:72px}` ห้ามเปลี่ยนตำแหน่ง/สีต่อเล่ม
  คัดลอก snippet จากเล่มไหนก็ได้ (ค้น `<!-- shelf-home`) วางต่อจาก `</style>` แรก
- CSS กล่องขั้นตอนใช้ `.steps > li` ไม่ใช่ `.steps li` (กันรายการย่อยกลายเป็นขั้นตอนใหม่)

### หมายเหตุรายเกม
- **Azul:** มีแค่ Master Chocolatier ไม่มีภาคอื่น
- **Splendor:** ที่เล่นประจำคือ The Orient แบบ 5 คน (กฎบ้าน)
- **Table Cooking:** กล่องเป็นฉบับแรก (ตลาดใช้เม็ดขาว ไม่มีเซฟ) ไม่ใช่ 2nd Edition ที่ขายตอนนี้
- **Avalon:** มีภาคเสริม Avalon X ฉบับไทย (Lancelot · Excalibur · Plot Cards) ชื่อการ์ดพล็อตภาษาไทยในคู่มือแปลเอง
- **Hues and Cues:** กล่องเป็นฉบับไทยชื่อ "สีสันบันเทิง" เล่นคำใบ้เป็นภาษาไทย คู่มืออิงคู่มือ EN ของ The Op
  กติกาจริงห้ามแค่ชื่อสีสามัญ ชื่อสีเฉพาะ (คราม ทอง ลาเวนเดอร์) ใช้ได้ ตารางเทียบชื่อสีไทยและการนับคำเป็นกฎบ้าน
- **Coyote:** กล่องเป็นฉบับไทย แต่หาคู่มือไทย PDF ไม่ได้ คู่มือเรียบเรียงจากฉบับอังกฤษ เน้นลำดับการเล่น
  ชื่อการ์ดตัวอย่างใช้ชื่ออังกฤษ (ผู้เล่นอ่านหน้าการ์ดไทยเอง)
- **Stool Pigeon:** กล่องเป็นฉบับอังกฤษ (Barrel Aged Games) ชื่อไทยที่ใช้คือ "มาเฟียนกพิราบ"
  แต้มการ์ดยึดคู่มือ PDF ทางการ (Stool Pigeon 7 · Bamboozle 5 · Vendetta 3 · Kingpin 1) ไม่ใช่ 10 แต้มแบบรีวิว GeekDad
  ช่วงเลขพยาน 2–10 กับเวลาเล่น 10–20 นาที ยังไม่ยืนยันจากกล่องจริง
- **Cat in the Box:** กล่องเป็นฉบับภาษาอังกฤษของ Hobby Japan เล่น 2–5 คน 30 นาที
  คู่มือในกล่องชื่อ "Experiment Manual" ไม่ใช่ต้นฉบับญี่ปุ่น 3–4 คน ต้องมีกติกา 2 คนและ 5 คนเสมอ
